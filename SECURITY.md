# Seguridad

Si encuentras una vulnerabilidad o un secreto expuesto en este repositorio o en
entramado.org, **no abras un issue público**. Comunícalo en privado:

- por un aviso privado de GitHub:
  <https://github.com/entramado-org/entramado/security/advisories/new>
- o por correo a **contacto@entramado.org**.

Incluye qué has encontrado, dónde y cómo reproducirlo. Se responderá lo antes
posible y se publicará la corrección cuando esté desplegada.

El sitio es de solo lectura: la API y el conector MCP no aceptan escrituras, y
el grafo de producción se regenera desde un seed versionado.
